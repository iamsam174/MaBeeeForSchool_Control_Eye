【MaBeee for School 制御アプリ (視線入力対応版)】このアプリは、乾電池型IoTデバイス「MaBeee for School (学校版 / Scratch対応版)」をWindows PCから制御するためのソフトウェアです。Tobii Eye Tracker 5などを利用した視線入力やマウス操作で、単3形以上の乾電池を電源とするオモチャなどを簡単に動かすことができます。【同梱ファイル】MabeeeForSchool_Control_Eye.exe: アプリ本体です。config_school.ini: 設定保存用ファイルです。削除してもアプリ起動時に自動生成されます。【使い方】1. 準備乾電池で作動するオモチャなどにMaBeee for Schoolをセットし、本体のメインスイッチをONにします。PCのBluetoothがONになっていることを確認してください。2. 接続`MabeeeForSchool_Control_Eye.exe` をダブルクリックして起動します。※セキュリティ警告が出た場合は「詳細情報」→「実行」を選択してください。左上の 「🔍 MaBeeeを探査」 ボタンを左クリックします。すぐ右のドロップダウンメニューから、お使いのMaBeee for School（`Scratch(.....)`と表示されます）を選択します。「接続」 ボタンを左クリックします。接続に成功すると「接続完了」と表示され、Beep音が鳴ります。3. 操作（動作モード）画面中央の大きな青いボタンを操作します。モード① (タイマー駆動): ボタンを左クリック（または注視＝視線をとどめる）すると、設定された秒数だけオモチャなどが動きます。モード② (ホバー駆動): ボタンの上にマウスポインター（または視線）が入るとタイマーが開始されます。モード③ (ダイレクト駆動): ボタンの上にマウスポインター（または視線）がある間だけオモチャなどが動き、はずすと即座に止まります。4. 便利機能[F11] キー: 画面を全画面表示に切り替えます。[1][2][3] キー: 動作モードを素早く切り替えます。[←][→] キー: タイマーの秒数を変更します。【困ったときは】モーターが回らない: 電池残量を確認してください。また、一度MaBeee for Schoolから単4乾電池を抜き、10秒ほど待ってから入れ直すと直る場合があります。接続できない: 他のアプリでMaBeeeを接続していないか確認してください。アプリが起動しない: Windows 10/11 (64bit) 環境が必要です。【注意事項】本ソフトは障害児・者の個人利用および教育用途を目的としています。商用利用や再配布については、開発元にご相談ください。
