# MaBeee for School 制御アプリ （視線入力対応版）

## 概要
視線入力（アイトラッキング）やマウス操作などを利用して、乾電池型IoTデバイス「MaBeee for School （学校版 / Scratch対応版）」をBluetooth経由で手軽にコントロールするWindows向けアプリケーションです。
Tobii Eye Tracker 5などを利用した視線入力やマウス操作で、単3形以上の乾電池を電源とするオモチャなどを簡単に動かすことができます。

## ダウンロードと起動方法

1. **ダウンロード**:
   - 本リポジトリのファイル一覧にある **`MabeeeForSchool_Control_Eye.zip`** をクリックし、詳細画面の「Download」または「Download raw file」ボタンを押してダウンロードします。
   - あるいは、リポジトリの **Releases** ページ（Version 1.1.0）のアセット一覧からも同じ `MabeeeForSchool_Control_Eye.zip` をダウンロードできます。
2. **解凍**:
   - ダウンロードした `MabeeeForSchool_Control_Eye.zip` を右クリックして「すべて展開」を選択し、解凍します。
3. **起動**:
   - 展開されたフォルダ内にある **`MabeeeForSchool_Control_Eye.exe`** をダブルクリックして起動します。

## 同梱ファイル
配布用のZIPファイル（`MabeeeForSchool_Control_Eye.zip`）を展開すると、以下のファイル群が含まれるフォルダが作成されます。

- **`MabeeeForSchool_Control_Eye.exe`**: アプリ起動用の実行ファイルです。
- **`_internal` フォルダ**: アプリの動作に必要なシステムファイル群です。※削除したり、フォルダ外へ移動させたりしないでください。
- **`config_school.ini`**: 設定保存用ファイルです。削除してもアプリ起動時に自動生成されます。
- **`LICENSE`**: ソフトウェアライセンス（MIT License）ファイルです。
- **`かんたんガイドMaBeeeForSchool_Control_Eyeアプリ.pdf`**: 本アプリの導入と設定手順を記載したPDFマニュアルです。

## 使い方

### 1. 準備
- 乾電池で作動するオモチャなどにMaBeee for Schoolをセットし、本体のメインスイッチをONにします。
- PCのBluetoothがONになっていることを確認してください。

### 2. 接続
1. `MabeeeForSchool_Control_Eye.exe` をダブルクリックして起動します。
   ※セキュリティ警告が出た場合は「詳細情報」→「実行」を選択してください。
2. 左上の **「🔍 MaBeeeを探査」** ボタンを左クリックします。
3. すぐ右のドロップダウンメニューから、お使いのMaBeee for School（`Scratch(.....)`と表示されます）を選択します。
4. **「接続」** ボタンを左クリックします。接続に成功すると「接続完了」と表示され、Beep音が鳴ります。

### 3. 操作（動作モード）
画面中央の大きな青いボタンを操作します。

- **モード①クリックまたは注視でタイマー実行 （タイマー駆動）**: ボタンを左クリック（または注視＝視線をとどめる）すると、設定された秒数だけオモチャなどが動きます。
- **モード②マウスオーバーでタイマー実行 （ホバー駆動）**: ボタンの上にマウスポインター（または視線）が入るとタイマーが開始されます。
- **モード③マウスポインターがボタン内にある間だけON （ダイレクト駆動）**: ボタンの上にマウスポインター（または視線）がある間だけオモチャなどが動き、はずすと即座に止まります。

### 4. 便利機能
- **[F11] キー**: 画面を全画面表示に切り替えます。
- **[1][2][3] キー**: 動作モードを素早く切り替えます。
- **[←][→] キー**: タイマーの秒数を変更します。
- **カスタマイズ可能なUI**: ボタンのサイズ（特大〜小）、タイマー秒数（1〜180秒）、操作音の有無をご利用環境に合せて簡単に変更できます。

## 動作環境
- OS: Windows 10 / Windows 11
- Bluetooth 4.0以降対応のPC（MaBeeeとの通信に使用）
- Webカメラ（※「カメラ1」「カメラ2」などの映像を表示する場合のみ必要。不要な場合は「カメラなし」を選択可）

## 困ったときは
- **モーターが回らない**: 電池残量を確認してください。また、一度MaBeee for Schoolから単4乾電池を抜き、10秒ほど待ってから入れ直すと直る場合があります。
- **接続できない**: 他のアプリでMaBeeeを接続していないか確認してください。
- **アプリが起動しない**: Windows 10/11 (64bit) 環境が必要です。
